## ✨ Features

- **📺 Interactive Terminal CLI Mockup**: A retro CLI simulator allowing users to explore portfolio sections (`about`, `skills`, `projects`, `contact`) through interactive command-line commands.
- **🎨 Modern Glassmorphism Design**: High-end styling using tailwind CSS, HSL-tailored dark modes, smooth gradients, and interactive cards that feel alive.
- **💡 Featured Projects Section**: Showcases key deep learning, AI planning, and classical ML systems with direct GitHub repository integrations.
- **📅 Experience & Education Timeline**: A clean, animated vertical journey mapping professional experience (Infosys Springboard) and academic milestones.
- **🏆 Credentials & Badges**: Prominently highlights HackerRank 5-Star Python ranking, 40+ GCP skill badges, and LeetCode problem-solving progress.
- **📱 Fully Responsive Design**: Seamlessly transitions between complex multi-column desktop environments and specialized mobile layouts.

## 🛠️ Technology Stack

- **Frontend Core**: React.js (Vite), JavaScript (ES6+), HTML5, CSS3
- **Animations**: Framer Motion (for physics-based transitions, fade-in lists, and micro-interactions)
- **Styling**: Tailwind CSS (with bespoke glassmorphic backdrop-filters and neon glow borders)
- **Icons**: React Icons, Lucide React, Simple Icons

## 💻 Interactive Terminal CLI Commands

Try typing these commands in the terminal mockup:
- `help` - Lists all available commands.
- `about` - Displays Shreedhar's background and development philosophy.
- `skills` - Outputs categorized skills (languages, frameworks, databases, LLM engineering, CS fundamentals).
- `projects` - Prints a quick-access numbered list of featured projects.
- `contact` - Displays direct links to Email, GitHub, LinkedIn, and phone.
- `clear` - Wipes the terminal history log clean.
